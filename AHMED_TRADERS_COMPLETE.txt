================================================================================
                    📋 HOW TO USE IN VISUAL STUDIO CODE
================================================================================

STEP 1: COPY THE PROJECT
-------------------------
1. Copy the entire "ahmed-traders" folder
2. Paste it to your desired location:
   
   Windows: C:\Users\YourName\Documents\ahmed-traders
   Mac:     /Users/YourName/Documents/ahmed-traders
   Linux:   /home/yourname/Documents/ahmed-traders


STEP 2: OPEN IN VS CODE
------------------------
1. Open Visual Studio Code
2. Click File → Open Folder
3. Select the "ahmed-traders" folder
4. Click Open


STEP 3: INSTALL DEPENDENCIES
-----------------------------
Terminal 1 (Backend):
   cd backend
   npm install

Terminal 2 (Frontend):
   cd frontend
   npm install


STEP 4: RUN THE APPLICATION
----------------------------
Terminal 1 (Backend):
   cd backend
   npm start

Terminal 2 (Frontend):
   cd frontend
   npm start

Browser opens at: http://localhost:3000


STEP 5: CREATE ADMIN USER
--------------------------
Use curl or Postman to create first admin:

curl -X POST http://localhost:5000/api/auth/register \
-H "Content-Type: application/json" \
-d '{"name":"Admin","email":"admin@ahmed.com","password":"admin123","role":"admin"}'


STEP 6: LOGIN
-------------
Email:    admin@ahmed.com
Password: admin123
