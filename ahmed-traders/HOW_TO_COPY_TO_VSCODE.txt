📋 STEP-BY-STEP INSTRUCTIONS
================================================================================

STEP 1: COPY THE PROJECT FOLDER
--------------------------------
1. Locate the "ahmed-traders" folder on your computer
2. Copy the ENTIRE folder (not just the contents)
3. Paste it to your desired location, for example:
   
   Windows:   C:\Users\YourName\Documents\ahmed-traders
   Mac:       /Users/YourName/Documents/ahmed-traders
   Linux:     /home/yourname/Documents/ahmed-traders


STEP 2: OPEN IN VISUAL STUDIO CODE
--------------------------------
Method A - Using File Menu:
   1. Open Visual Studio Code
   2. Click "File" → "Open Folder"
   3. Navigate to where you pasted "ahmed-traders"
   4. Select the "ahmed-traders" folder
   5. Click "Open" or "Select Folder"

Method B - Using Command Line:
   1. Open Terminal/Command Prompt
   2. Navigate to the folder: cd /path/to/ahmed-traders
   3. Type: code .
   4. Press Enter

Method C - Drag and Drop:
   1. Open Visual Studio Code
   2. Drag the "ahmed-traders" folder from your file explorer
   3. Drop it onto the VS Code window


STEP 3: INSTALL DEPENDENCIES
--------------------------------
1. In VS Code, press Ctrl+` (backtick) to open terminal
2. Install backend dependencies:
   
   cd backend
   npm install

3. Open a new terminal (click + icon)
4. Install frontend dependencies:
   
   cd frontend
   npm install


STEP 4: CONFIGURE ENVIRONMENT
--------------------------------
1. In VS Code file explorer, go to backend folder
2. The .env file is already created with default settings
3. If needed, you can edit it (MongoDB connection, port, etc.)


STEP 5: RUN THE APPLICATION
--------------------------------
Terminal 1 (Backend):
   cd backend
   npm start

Terminal 2 (Frontend):
   cd frontend
   npm start

Your browser will open automatically at http://localhost:3000
